# 🎵 Telegram Music Bot

[README](README.md) • [Contributing](CONTRIBUTING.md) • [Security](SECURITY.md)

Асинхронный Telegram-бот на Python (aiogram 3, yt-dlp) для поиска, скачивания и прослушивания музыки в формате **M4A / MP3** со стриминговых платформ и по текстовым поисковым запросам. Бот автоматически извлекает метаданные, нормализует и встраивает квадратные обложки альбомов (1:1), поддерживает inline-поиск и позволяет редактировать аудио-теги прямо в мессенджере.

---

## ✨ Возможности

- 🔗 **Поддержка стриминговых платформ:**
  - 🟢 **Spotify**: ссылки на треки, альбомы и плейлисты (`open.spotify.com`, `spotify.link`) — извлечение канонических метаданных и обложек с последующим точным поиском аудиопотока и fallback-маршрутами.
  - 🔴 **YouTube / YouTube Music**: ссылки на видео, треки, Shorts и плейлисты (`youtube.com`, `music.youtube.com`, `youtu.be`) — прямая загрузка аудиопотока через yt-dlp с поддержкой обхода ограничений (Deno/Node.js, cookie, прокси).
  - 🍎 **Apple Music**: ссылки на треки и альбомы `music.apple.com` — получение точных метаданных через официальный iTunes Lookup API и поиск соответствующего аудио.
  - 🟠 **SoundCloud**: прямая загрузка доступных аудиопотоков по ссылкам `soundcloud.com` и использование в качестве резервного источника при поиске.
  - 🟡 **Яндекс Музыка**: ссылки на треки и альбомы (при наличии `YANDEX_MUSIC_TOKEN` через прямой API-клиент либо fallback-поиск).
  - 🔵 **VK Музыка**: ссылки на аудиозаписи и плейлисты ВКонтакте (при настройке `VK_TOKEN` и регионального прокси).
  - 🔎 **Текстовый поиск**: отправка названия песни и исполнителя (например, `MiyaGi - Captain` или `The Weeknd - Blinding Lights`) с автоматическим ранжированием кандидатов и загрузкой лучшего совпадения.
- ⚡ **Модификаторы звучания (DSP)**:
  - Автоматическое распознавание модификаторов в запросах: `slowed`, `sped up`, `reverb`, `nightcore`, `acoustic`, `remix` и др.
  - Подбор готовых студийных версий либо аккуратная обработка на лету через фильтры FFmpeg.
- 🏷️ **Автоматические теги и обложки**:
  - Встраивание тегов исполнителя, названия и альбома через Mutagen (MP4 atoms для M4A, ID3v2.4 для MP3).
  - Автоматическая обрезка обложек до квадратных пропорций 1:1 без искажения изображения.
- ✂️ **Встроенный редактор тегов**:
  - Интерактивная кнопка под каждым скачанным треком для изменения автора, названия и обложки прямо в Telegram.
- 💬 **Inline Mode**:
  - Быстрый поиск музыки прямо в строке ввода любого диалога (`@имя_бота запрос`) с отправкой трека в один клик.
- 📊 **Прогресс-индикатор**:
  - Информативное динамическое отображение этапов загрузки и обработки трека в реальном времени.
- 💎 **Поддержка проекта (криптодонаты)**:
  - Команда `/donate` с удобным выбором валют (USDT TRC20, BNB Smart Chain (BEP20), Bitcoin), QR-кодами высокого разрешения и кликабельным копированием адресов кошельков.

## ⚡ Особенности

- **Direct M4A / AAC Stream**: передача оригинального аудиопотока в контейнере M4A без лишней перекодировки в MP3 экономит ресурсы CPU и сокращает время обработки трека.
- **Конкурентный параллельный поиск**: одновременный опрос доступных источников для минимизации задержки выбора лучшего кандидата.
- **Многоуровневое кэширование**: двухуровневая архитектура (L1 RAM LRU + SQLite persistent database) для быстрой повторной отправки ранее скачанных треков по file_id без повторной загрузки.
- **Встроенный VLESS / sing-box маршрутизатор**: поддержка автоматического запуска sing-box для разделения зарубежного и локального трафика при наличии ограничений доступа.
- **Защита ресурсов**: ограничение конкурентных загрузок через семафоры и однопоточный FFmpeg для стабильной работы даже на контейнерах с ограниченным объёмом памяти.
- **Автоочистка**: временные медиафайлы удаляются сразу после отправки в чат.

## 🎧 Форматы

- **M4A (AAC)** — основной формат по умолчанию. Обеспечивает максимальную скорость скачивания, экономию трафика и оригинальное качество аудиопотока.
- **MP3** — поддержка конвертации аудио с настраиваемым битрейтом (128 / 192 / 256 / 320 кбит/с).
- **Метаданные** — теги MP4 (для M4A) и ID3v2.4 (для MP3) с вшитыми обложками JPEG/PNG.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/dbshka/tg-music-bot.git
cd tg-music-bot
```

### 2. Создание виртуального окружения
```bash
python -m venv venv

# Linux / macOS:
source venv/bin/activate

# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Установка системных утилит
Для работы бота необходим **FFmpeg**:
- **Ubuntu / Debian**: `sudo apt update && sudo apt install -y ffmpeg`
- **macOS**: `brew install ffmpeg`
- **Windows**: `winget install Gyan.FFmpeg` или `choco install ffmpeg`

*(Опционально)* Для решения JavaScript-челленджей YouTube движком `yt-dlp` рекомендуется установить **Node.js** или **Deno**.

### 5. Настройка конфигурации
Скопируйте файл с примером настроек:
```bash
cp .env.example .env
```
Откройте `.env` и укажите токен вашего бота, полученный у [@BotFather](https://t.me/BotFather):
```ini
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

### 6. Запуск бота
```bash
python bot.py
```

## ⚙️ Конфигурация

Все настройки задаются через переменные окружения в файле `.env`:

| Переменная | Обязательная | По умолчанию | Описание |
|---|:---:|:---:|---|
| `BOT_TOKEN` | **Да** | — | Токен Telegram-бота от [@BotFather](https://t.me/BotFather) |
| `AUDIO_BITRATE` | Нет | `192` | Битрейт при конвертации аудио (128, 192, 256, 320) |
| `PROXY` | Нет | — | Общий прокси для подключения бота к Telegram (`http://...` или `socks5://...`) |
| `YOUTUBE_PROXY` | Нет | — | Отдельный прокси для загрузки с YouTube / иностранных платформ |
| `RUSSIAN_PROXY` | Нет | — | Прокси для доступа к региональным сервисам (Яндекс Музыка, ВК) |
| `VLESS_URL` | Нет | — | VLESS-ссылка или URL подписки для автоматического запуска SOCKS5 через sing-box (зарубежный маршрут) |
| `VLESS_RU_URL` | Нет | — | VLESS-ссылка или URL подписки для регионального маршрута (РФ) |
| `YANDEX_MUSIC_TOKEN` | Нет | — | OAuth-токен Яндекс Музыки для доступа к трекам высокого качества |
| `VK_TOKEN` | Нет | — | Токен авторизации ВКонтакте для работы с закрытыми треками |
| `ADMIN_ID` | Нет | — | Числовой ID администратора в Telegram для команд `/stats` и `/broadcast` |
| `PORT` | Нет | `7860` | Порт для встроенного HTTP healthcheck-сервера |
| `CUSTOM_API_SERVER` | Нет | — | URL альтернативного или локального сервера Telegram Bot API |
| `DB_PATH` | Нет | `bot_database.db` | Путь к файлу базы данных SQLite |

## 🐳 Docker

Проект содержит готовый `Dockerfile` с предустановленными FFmpeg, Node.js, Deno и sing-box:

```bash
# Сборка образа
docker build -t tg-music-bot .

# Запуск контейнера
docker run -d \
  --name tg-music-bot \
  --restart unless-stopped \
  --env-file .env \
  -p 7860:7860 \
  tg-music-bot
```

Healthcheck-сервер доступен по адресу `http://localhost:7860/health` и возвращает статус `200 OK`.

## 🔐 Безопасность

- **Не публикуйте `.env`**: файл конфигурации должен оставаться строго на локальной машине или сервере. Он автоматически добавлен в `.gitignore`.
- **Telegram Bot Token**: токен бота (`BOT_TOKEN`) даёт полный контроль над ботом — никогда не передавайте его в коммиты или открытые логи.
- **Cookies (`cookies.txt`)**: сессионные cookies браузера содержат персональные данные авторизации. Не добавляйте их в репозиторий; на сервере используйте защищённые секретные файлы.
- **VLESS credentials**: ссылки `vless://`, приватные ключи Reality, UUID и параметры серверов должны передаваться исключительно через защищённые переменные окружения.
- **Пароли и приватные ключи (private keys)**: не сохраняйте в коде или документации SSH-ключи, сертификаты, API-ключи или пароли.
- **Безопасность URL**: встроенная защита блокирует запросы к приватным и локальным IP-диапазонам (SSRF), предотвращая атаки на внутреннюю инфраструктуру.

Подробнее о политике безопасности проекта см. в файле [SECURITY.md](SECURITY.md).
