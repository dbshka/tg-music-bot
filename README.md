# 🎵 Telegram Music Downloader Bot (v2.0.0)

Высокопроизводительный асинхронный Telegram-бот для загрузки музыки в формате **MP3** по ссылкам из популярных стриминговых сервисов, а также по текстовому названию песни.

## ✨ Возможности

- 🔗 **Поддержка платформ:**
  - 🟡 **Яндекс Музыка**: треки (`/track/...`), альбомы и синглы (`/album/...`), артисты (`/artist/...`), плейлисты, короткие мобильные ссылки `ya.cc/t/...` и `clck.ru`. Прямой парсинг состояния Next.js Server Components в обход зарубежных геоблокировок!
  - 🟢 **Spotify**: треки, альбомы (`open.spotify.com`), короткие ссылки `spotify.link/...` (oEmbed + iTunes Search API).
  - 🍎 **Apple Music**: треки и альбомы `music.apple.com` через официальный iTunes Lookup API.
  - 🔴 **YouTube / YouTube Music**: `youtube.com`, `music.youtube.com`, `youtu.be`, `YouTube Shorts` с умным обходом дата-центровых IP-блокировок.
  - 🟠 **SoundCloud**: прямая загрузка аудиофайлов без пережатия и многоуровневый fallback.
  - 🔵 **VK Музыка / VK Видео**: `vk.com/...`.
  - 🎸 **Bandcamp, TikTok, Vimeo и др.**
- ⚡ **Архитектура v2.0.0**:
  - **Connection Pooling**: единый пул соединений `aiohttp.ClientSession` (-200 мс на сетевой запрос).
  - **L1 RAM LRU кэш**: моментальная отдача закэшированных треков за **0.01 мс**.
  - **1-pass Mutagen ID3**: однопроходная запись метаданных и обложек альбомов без повторной перезаписи файлов.
  - **Защита ресурсов**: семафор `Semaphore(3)` с защитой от CPU starvation на микро-контейнерах (Render Free 0.1 vCPU).
- 🔎 **Поиск по названию**: можно просто написать имя исполнителя и песню (например: `Eminem - Lose Yourself`), бот найдёт и пришлёт трек.
- 🏷️ **ID3-теги**: автоматическое сохранение корректного названия, исполнителя и обложки альбома.
- ✂️ **Встроенный редактор тегов**: кнопка `[ ✏️ Изменить теги ]` под каждым скачанным треком для изменения автора, названия и обложки.
- 🧹 **Автоочистка**: временные файлы удаляются сразу после отправки трека в чат.

## 🚀 Быстрый старт

### 1. Получение токена бота
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите имя и username бота (например, `MySuperMusicBot`).
4. Скопируйте полученный **HTTP API Token**.

### 2. Настройка конфигурации
Откройте файл `.env` в папке проекта и укажите ваш токен:
```ini
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
AUDIO_BITRATE=192
```

### 3. Запуск бота
В терминале (PowerShell или Командная строка) в папке проекта:
```powershell
.\venv\Scripts\python.exe bot.py
```

После запуска бот напишет:
`[INFO] root: Бот запускается...`

Откройте вашего бота в Telegram, нажмите `/start` и отправьте любую ссылку на музыку!

## 🛠️ Зависимости

- **Python**: 3.10+
- **FFmpeg**: должен быть установлен в системе (уже установлен и настроен в системе).
- Библиотеки Python:
  - `aiogram 3.x` — современный асинхронный фреймворк для Telegram-ботов
  - `yt-dlp` — движок загрузки аудиопотоков
  - `aiohttp` — асинхронный HTTP-клиент для метаданных
  - `mutagen` — работа с MP3 ID3-тегами
  - `pillow` — обработка обложек треков
