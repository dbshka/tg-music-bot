# 🎵 Telegram Music Downloader Bot

Telegram-бот для загрузки музыки в формате **MP3** по ссылкам из популярных музыкальных сервисов, а также по текстовому названию песни.

## ✨ Возможности

- 🔗 **Поддержка платформ:**
  - **YouTube / YouTube Music**
  - **Spotify** (автоматическое извлечение метаданных и обложки через oEmbed / iTunes API + поиск аудио)
  - **SoundCloud**
  - **Apple Music** (распознавание трека по ID + поиск аудио)
  - **VK Музыка**
  - **TikTok, Bandcamp, Vimeo и др.**
- 🔎 **Поиск по названию**: можно просто написать имя исполнителя и песню (например: `Eminem - Lose Yourself`), бот найдет и пришлет трек.
- 🏷️ **ID3-теги**: автоматическое сохранение корректного названия, исполнителя и обложки альбома.
- ⚡ **Конвертация в MP3**: на базе FFmpeg с настраиваемым битрейтом (по умолчанию 192 kbps).
- 🧹 **Автоочистка**: временные файлы удаляются сразу после отправки трека в чат.

## 🚀 Быстрый старт

### 1. Получение токена бота
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите имя и username бота (например, `MySuperMusicBot`).
4. Скопируйте полученный **HTTP API Token**.

### 2. Настройка конфигурации
Откройте файл `.env` в папке проекта и укажите ваш токен:
```ini
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
AUDIO_BITRATE=192
```

### 3. Запуск бота
В терминале (PowerShell или Командная строка) в папке проекта:
```powershell
.\venv\Scripts\python.exe bot.py
```

После запуска бот напишет:
`[INFO] root: Бот запускается...`

Откройте вашего бота в Telegram, нажмите `/start` и отправьте любую ссылку на музыку!

## 🛠️ Зависимости

- **Python**: 3.10+
- **FFmpeg**: должен быть установлен в системе (уже установлен и настроен в системе).
- Библиотеки Python:
  - `aiogram 3.x` — современный асинхронный фреймворк для Telegram-ботов
  - `yt-dlp` — движок загрузки аудиопотоков
  - `aiohttp` — асинхронный HTTP-клиент для метаданных
  - `mutagen` — работа с MP3 ID3-тегами
  - `pillow` — обработка обложек треков
